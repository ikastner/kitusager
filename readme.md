# KitUsager

Application mobile Convertigo NGX (v**1.4.0**) pour collecter des verbatims usagers sur salon : wizard 5 étapes, stockage **local** sur la tablette, échange de fiches par import / export JSON ou CSV.

La base de données et la synchronisation serveur sont **prévues dans le code, pas encore branchées**.
